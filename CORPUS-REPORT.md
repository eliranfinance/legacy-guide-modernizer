# Corpus distillation report

## Input reviewed

- 68 tagged items in the supplied folder, including nested content and temporary Word lock files
- 65 regular files extracted for text review
- 623,178 extracted characters and about 60,596 whitespace-delimited words
- 64 text/Word documents plus one ZIP archive; the archive contained a GameMaker project and a duplicate Word guide

## Reusable gold

| Theme | What survives | Modernization rule |
|---|---|---|
| PC building | Match components to goals, budget, thermals, compatibility, and upgrade path | Use current part specifications and a compatibility checklist |
| Maintenance | Dust, heat, airflow, backups, and observability affect reliability | Require power-off, cooling, ESD care, and a measurable before/after check |
| Reinstall and recovery | Plan partitions, backups, drivers, and recovery before changing a system | Prefer supported recovery media and verify backups before destructive steps |
| Networking | Troubleshoot from physical link through configuration and service checks | Keep diagnostics local and authorized; avoid third-party disruption |
| Game creation | Start with a small loop, assets, events, testing, and incremental levels | Teach transferable concepts and current tools rather than old UI paths |
| Graphics workflows | Layered edits, repeatable steps, and export checks are teachable | Map old Photoshop actions to current equivalents and preserve originals |
| Media conversion | Input format, target device, subtitles, encoding, and validation matter | Prefer legal source material and current codecs/tools |
| Security | Historical malware descriptions can teach indicators and defenses | Never preserve attack instructions; convert to detection, hardening, and recovery |

## Excluded or transformed

The archive also contains password cracking, account compromise, malware creation, denial-of-service, piracy/bypass, exposed IP addresses, and old download links. Those details were not carried into the skill. They are covered by a safety boundary that redirects to authorized recovery, incident response, defensive analysis, and local labs.

## Why this is useful

The durable product is a method for rescuing practical knowledge from obsolete archives. It prevents the common failure mode where an assistant repeats a 2006 command, dead link, unsafe shortcut, or version-specific UI path as if it were current.
